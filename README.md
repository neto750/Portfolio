# Portfólio — Nelson Allein Neto

Portfólio pessoal responsivo feito com HTML, CSS e JavaScript, com animações de entrada, brilho que acompanha o cursor e menu adaptado para celular.

## Arquivos

- `index.html`: conteúdo e seções do site.
- `style.css`: identidade visual, layout responsivo e animações.
- `script.js`: dados pessoais, links e interações.

## Seus links já configurados

Os dados estão no início de `script.js` e podem ser alterados no objeto `PORTFOLIO`. Os links de GitHub, LinkedIn, e-mail e repositório da Pokédex já foram preenchidos. A demonstração online da Pokédex permanece vazia até que você hospede o projeto.

## Testar localmente

1. Extraia a pasta do ZIP.
2. Abra `index.html` no navegador ou abra a pasta no VS Code e use uma extensão como Live Server.
3. Clique nos links de GitHub, LinkedIn, e-mail e no repositório da Pokédex para conferir se estão corretos.

## Publicar gratuitamente no GitHub Pages

1. Crie um repositório público chamado `portfolio` na sua conta do GitHub.
2. Envie `index.html`, `style.css` e `script.js` para a raiz do repositório. Pode enviar este README também.
3. No repositório, abra **Settings → Pages**.
4. Em publicação por branch, escolha `main` e a pasta `/ (root)` e salve.
5. Aguarde o GitHub Pages publicar o endereço apresentado na própria página de configurações.
6. Teste o link em uma janela anônima e depois adicione-o ao seu perfil do LinkedIn.

Observação: GitHub Pages hospeda este portfólio estático. Para publicar uma aplicação PHP como a Pokédex, será necessária uma hospedagem que execute PHP.
